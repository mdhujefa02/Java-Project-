# Java Projects Collection

This repository contains a collection of Java applications and games developed to demonstrate various concepts and functionalities of Java programming. Each project is structured as an independent Java application.

## Projects List
1. **Calculator.java**
2. **CalendarApplication.java**
3. **Currency_Converter.java**
4. **EmployeeManagment.java**
5. **HangmanGame.java**
6. **HotelManagementSystem.java**
7. **Library_management.java**
8. **QuizGame.java**
9. **tic_tac_toe.java**

## Project Descriptions
### 1. Calculator.java
A simple command-line calculator that performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

### 2. CalendarApplication.java
A program that displays calendar functionalities including viewing months and years.

### 3. Currency_Converter.java
An application to convert currencies between different denominations based on predefined exchange rates.

### 4. EmployeeManagment.java
A basic employee management system that allows the user to manage employee details like adding, updating, and deleting employee records.

### 5. HangmanGame.java
A classic Hangman word-guessing game implemented in Java.

### 6. HotelManagementSystem.java
A simple hotel management system to manage bookings, customer details, and room assignments.

### 7. Library_management.java
An application to manage library operations such as issuing, returning, and searching books.

### 8. QuizGame.java
A fun quiz game where users answer questions and receive scores based on correct answers.

### 9. tic_tac_toe.java
A simple two-player Tic Tac Toe game with a text-based interface.

## Setup and Usage
### Prerequisites
- Java Development Kit (JDK) 8 or higher
- A code editor (such as IntelliJ IDEA, Eclipse, or VSCode).
